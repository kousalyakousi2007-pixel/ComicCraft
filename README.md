# ComicCraft – AI Comic Story Creator

## Project Overview

ComicCraft is an AI-powered web application that creates personalized comic stories from user-provided story ideas.

The application uses AI to generate story content and comic-style illustrations and presents them as a panel-by-panel comic.

## Project Objective

The main objective of ComicCraft is to make comic creation easier for users without professional writing or drawing skills.

## Key Features

- AI-powered story generation
- Personalized character and story input
- Comic panel generation
- AI-generated illustrations
- Comic preview
- PDF export
- Simple web-based interface

## Technologies Used

- Python
- FastAPI
- HTML
- CSS
- Gemini AI Models
- ReportLab

## Project Workflow

1. User enters a story idea.
2. ComicCraft processes the user input.
3. AI generates the story outline.
4. AI generates the comic story.
5. Comic illustrations are generated.
6. The panels are arranged into a comic.
7. The final comic can be viewed and exported as a PDF.

## Project Phases

The project is developed in the following 8 phases:

1. Brainstorming & Ideation
2. Requirement Analysis
3. Project Design
4. Project Planning
5. Project Development
6. Project Testing
7. Project Documentation
8. Project Demonstration

## Project Output

The final output is an AI-generated comic story presented in multiple comic panels and can be exported as a PDF.
